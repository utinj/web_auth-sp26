Nine to NaN

A turn based puzzle battler based on math. This game was made for a game jam, going after the theme "9 to 5". The entire game was developed in 5 days!

Game Jam Explanation and Feature

Controls

[Space]: Advance dialogue

[q] [w] [e]: Select and use skills

[a] [d]: Change target
